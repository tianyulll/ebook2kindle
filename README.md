Ebook conversion and send to device

## Features
- Accepts txt and convert to epub. 
- Automatically handles encoding and language.
- Detects Chapters in `zh` and `en`.
- Style tailored for kindle-compatibilitly.
- Allows batch conversion - Just drop all files at once!
- Send to your device via your email
适配中文小说的txtEPUB转换器。自带章节提取，首段和段落缩进排版。可以邮件发送到Kindle。虽然更好的方法是直接使用amazon的send to kindle功能。

## Installation 
The easiest way is to download the .zip folder and execute and .app application on MacOS. You can unzip the file and right click to open. \
Alternatively you can clone this repo and build from source. 

## Usage
the converter is pretty self-explainatory. For sending to device function. You will need to:
1. Whitelist your email on you kindle device setting. Otherwise it will be blocked.
2. If sending from a gmail account you would need to use app-specific password, not your regular password.
I have not tested it on other email - honestly using Amazon's send to kindle after conversion is the best solution.
