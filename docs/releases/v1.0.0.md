# ebook2kindle v1.0.0

ebook2kindle 1.0 is the first formal release of the redesigned desktop app for converting TXT books to Kindle-ready EPUB files and optionally delivering them to Kindle.

## Download

- **Apple Silicon Mac, macOS 13+:** `ebook2kindle-v1.0.0-macos-arm64.zip`
- **Integrity file:** `SHA256SUMS.txt`

Download both files from this release, then run `shasum -a 256 -c SHA256SUMS.txt` in their directory. Extract the ZIP and move `ebook2kindle.app` to Applications.

## Highlights

- Generates deterministic minimalist covers automatically from detected English or Chinese title and author metadata.
- Uses light cover backgrounds and dark typography for strong visibility on black-and-white Kindle screens.
- Adds direct access to Amazon's official Send to Kindle website from the delivery sidebar.
- Supports batch drag-and-drop conversion, per-book status, and adjustable paragraph styling.
- Preserves opening text and existing files through numbered output names and atomic publication.
- Supports encrypted credential storage, STARTTLS or implicit TLS, structured delivery results, and bounded retry handling.
- Uses a rounded native Qt interface with responsive background conversion and delivery.
- Fixes the standard macOS Command-W close-window shortcut.

## Important notes

- The application is built for Apple Silicon (`arm64`) and requires macOS 13 or later. Intel Mac and Windows packages are not included.
- The app has an ad-hoc signature but is not Apple Developer ID signed or notarized. macOS may require approval under Privacy & Security after you verify the download source and checksum.
- TXT conversion requires a writable filesystem with hard-link support, such as a local APFS volume.
- Existing EPUB files pass through unchanged; automatic covers are added only to converted TXT books.
- “Submitted” means the configured mail provider accepted the message, not that Amazon has completed Kindle delivery.
- Live SMTP delivery with an independent test account and installation on a clean macOS account remain outstanding verification items.
