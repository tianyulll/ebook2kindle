# ebook2kindle v1.0-beta.2

This beta brings a redesigned Qt desktop app for batch TXT-to-EPUB conversion and optional Kindle delivery.

## Download

- **Apple Silicon Mac, macOS 13+:** `ebook2kindle-v1.0-beta.2-macos-arm64.zip`.
- Extract the ZIP and move `ebook2kindle.app` to Applications.
- The app is not Developer ID signed or notarized. If blocked, use [Apple's official opening instructions](https://support.apple.com/guide/mac-help/mh40616/mac) after verifying the source.
- Download `SHA256SUMS.txt` beside the ZIP and run `shasum -a 256 -c SHA256SUMS.txt` to verify integrity.
- No Intel Mac or Windows binary is included.

## Changes

- Rounded Qt interface, batch queue, background processing, and per-book status.
- Main-window paragraph indent and spacing controls.
- Direct port entry and visible STARTTLS / Implicit TLS selection.
- Certificate-verified TLS mail submission and OS credential-store password storage.
- Existing EPUBs are preserved with numbered output filenames and atomic publication.
- Opening text before the first chapter is retained.
- SMTP cleanup errors no longer cause duplicate submission of accepted messages.
- English installation documentation and a [Chinese usage guide](https://github.com/tianyulll/ebook2kindle/blob/v1.0-beta.2/docs/USAGE.zh-CN.md).

## Verification and limitations

20 automated tests pass, including output-collision, failed-write, preface, and SMTP retry coverage. Both Settings pages were visually checked at the minimum size; the build ZIP passed its integrity check.

Live SMTP delivery and installation on a clean Mac account remain unverified. Conversion requires a writable filesystem with hard-link support, such as APFS. “Submitted” means accepted by the mail provider, not confirmed Kindle receipt. Manually sending again submits all prepared books again.
